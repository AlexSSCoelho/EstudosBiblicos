# Esboços Manuais de Pregações (Pasta Local)

Coloque nesta pasta as fotos, digitalizações ou PDFs dos seus esboços manuais de pregações para transcrição e estruturação no módulo **Pregações**.

Todos os arquivos colocados aqui (exceto este `README.md`) estão listados no `.gitignore` e **não são enviados para o repositório público no GitHub**.
